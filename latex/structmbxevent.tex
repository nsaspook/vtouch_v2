\doxysubsection{Detailed Description}
Every time a message from some Mbx is expected, a new mbxevent element is created, and added to the prepared linked list. 

As soon as the expected message is received, the element is removed from the prepared linked list, two elements are appended to \doxylink{structmbxevent_a02dfd0e637bc54d3a77278fbf05312da}{mbxevent\+::cmd} (received message and the reply mailbox).

Finally, the event is pushed to Tcl\textquotesingle{}s event queue for further handling. As soon as Tcl is ready to handle it, \doxylink{structmbxevent_a02dfd0e637bc54d3a77278fbf05312da}{mbxevent\+::cmd} is executed.
