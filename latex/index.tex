\chapter{Mbx package for Tcl}
\hypertarget{index}{}\label{index}\index{Mbx package for Tcl@{Mbx package for Tcl}}
\hypertarget{index_intro_sec}{}\doxysection{\texorpdfstring{Introduction}{Introduction}}\label{index_intro_sec}
This package allows Tcl to interface with Brooks Software, mainly CELLworks and Grapheq, by communicating to its Mbx bus. See\+:
\begin{DoxyItemize}
\item \href{http://www3.brooks.com/pages/223_cellworks_grapheq.cfm}{\texttt{ http\+://www3.\+brooks.\+com/pages/223\+\_\+cellworks\+\_\+grapheq.\+cfm}}
\end{DoxyItemize}

Each Mbx message box has a name and a type. Opening a message box in Tcl goes as follows. First, make the Mbx package available to your script. Then define the MBX name you want to use. For example, if you have your MBX name defined as {\ttfamily hostname}\+\_\+mbx, you can simply do\+:
\begin{DoxyItemize}
\item {\ttfamily package require Mbx}
\item {\ttfamily mbx name \$env(\+HOSTNAME)\+\_\+mbx}
\end{DoxyItemize}

This only has to be done once. Then you can open a mailbox\+:


\begin{DoxyItemize}
\item {\ttfamily set box \mbox{[}mbx open \texorpdfstring{$<$}{<}boxname\texorpdfstring{$>$}{>} \texorpdfstring{$<$}{<}type\texorpdfstring{$>$}{>}\mbox{]}}
\end{DoxyItemize}

The type normally will be "{}m"{} (only open when it doesn\textquotesingle{}t exist yet, otherwise use the existing one), but can be any type described in the Brooks manual.

If you expect something from a mailbox, you can do\+:
\begin{DoxyItemize}
\item {\ttfamily \$box receive {\itshape code} ?{\itshape code} ...? }
\end{DoxyItemize}

Then, as soon as the message box receives a message your code will be executed. If \texorpdfstring{$<$}{<}code\texorpdfstring{$>$}{>} is left out, the command returns the code that is to be executed for this mailbox. If {\itshape code} is the empty string, then the receive is canceled.

If you want to send something to a mailbox and expect a reply on some other mailbox, then you can do\+:
\begin{DoxyItemize}
\item {\ttfamily \$box send \texorpdfstring{$<$}{<}message\texorpdfstring{$>$}{>} ?\texorpdfstring{$<$}{<}replybox\texorpdfstring{$>$}{>}?}
\end{DoxyItemize}

Finally, you can close the mailbox\+:
\begin{DoxyItemize}
\item {\ttfamily \$box close}
\end{DoxyItemize}

This command has the effect that the \$box command will be removed, and that any pending receives will be canceled. There are more commands, which are described in commands\+\_\+sec\hypertarget{index_install_sec}{}\doxysection{\texorpdfstring{Installation}{Installation}}\label{index_install_sec}
\hypertarget{index_step1}{}\doxysubsection{\texorpdfstring{Step 1\+: adapt the Makefile for your compiler.}{Step 1: adapt the Makefile for your compiler.}}\label{index_step1}
All there is is a single C-\/file (\doxylink{tclmbx_8c}{tclmbx.\+c}), which just needs to be compiled as a shared library (libtclmbx.\+so) for your platform. It needs to be linked with lib\+Cw.\+a and libtclstub.\+a, and the header files \texorpdfstring{$<$}{<}CELLworks/mbx.\+h\texorpdfstring{$>$}{>} and \texorpdfstring{$<$}{<}tcl.\+h\texorpdfstring{$>$}{>} \texorpdfstring{$<$}{<}CELLworks/\+CWstring.\+h\texorpdfstring{$>$}{>} need to be available. That\textquotesingle{}s all.\hypertarget{index_step2}{}\doxysubsection{\texorpdfstring{Step 2\+: run make.}{Step 2: run make.}}\label{index_step2}
This will produce the file libtclmbx.\+so, which -\/ together with Mbx-\/?.?.?.tm -\/ is everything you will need.\hypertarget{index_step3}{}\doxysubsection{\texorpdfstring{Step 3\+: copy Mbx-\/?.?.?.\+tm and libtclmbx.\+so anywhere}{Step 3: copy Mbx-?.?.?.tm and libtclmbx.so anywhere}}\label{index_step3}
that Tcl can find it. Or, just let Tcl know where it is\+:
\begin{DoxyItemize}
\item \+::tcl\+::tm\+::path add \texorpdfstring{$<$}{<}directory\texorpdfstring{$>$}{>}
\item set the environment variable TCL8\+\_\+5\+\_\+\+TM\+\_\+\+PATH to \texorpdfstring{$<$}{<}directory\texorpdfstring{$>$}{>}
\end{DoxyItemize}\hypertarget{index_commands_sec}{}\doxysection{\texorpdfstring{Mbx Commands}{Mbx Commands}}\label{index_commands_sec}
The Mbx command has 6 subcommands\+:
\begin{DoxyItemize}
\item buffersize\+: set or get the buffersize
\item delay\+: set or get the maximum delay for polling
\item info\+: get a list of all available mailboxes
\item name\+: get or set the name of the MBX
\item open\+: open a mailbox
\item version\+: display the version of the Mbx library (empty if not present)
\end{DoxyItemize}

If the \textquotesingle{}buffersize\textquotesingle{}, \textquotesingle{}delay\textquotesingle{} and \textquotesingle{}name\textquotesingle{} commands have an additional argument, this argument will be used to set the parameter. Otherwise the current value of this parameter is returned.

The open command has the following form\+:
\begin{DoxyItemize}
\item open ?\texorpdfstring{$<$}{<}options\texorpdfstring{$>$}{>}? \texorpdfstring{$<$}{<}boxname\texorpdfstring{$>$}{>} ?\texorpdfstring{$<$}{<}code\texorpdfstring{$>$}{>} ...?
\end{DoxyItemize}

If \texorpdfstring{$<$}{<}code\texorpdfstring{$>$}{>} is specified and not the empty string, then this code will be executed as soon as a message arrives in the mailbox. See also the \textquotesingle{}receive\textquotesingle{} command for the exact syntax.
